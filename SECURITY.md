# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it privately.
Do not open public GitHub issues for security vulnerabilities.

Please contact the maintainer directly via GitHub or at: `hi.nurfarhad@gmail.com`.

Include detailed steps to reproduce the issue and a proof-of-concept file if applicable.
We will acknowledge receipt within 48 hours and work with you to validate and resolve the issue.
